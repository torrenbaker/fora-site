# fora — marketing site

Static marketing site for fora. One file, no build step, no backend.

- `index.html` — the entire site (Poppins/Anton/Playfair via Google Fonts CDN)

## Local preview
Open `index.html` in a browser, or:
```
npx serve .
```

## Deploy
Hosted on GitHub Pages (Settings → Pages → Deploy from branch → main, / root).
Custom domain via Cloudflare comes later — do not add a CNAME file until the domain is live.
